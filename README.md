# sd-forge-random_prompt_pro
##简单介绍
-SD-WebUI 提示词生成 + 随机图抓取 + 分页管理插件
-这个插件的功能适合用于没有灵感想不出新颖提示词的人员使用
-主要功能是随机抽取在（api或者本地txt文件抽取随机tag）并组成一段完整的提示词
-这边需要注意的是，本地文件需要自己去填充大量不同的提示词，用于在抽取的时候使用，可使用逗号分隔，txt的文件目录是D：\stable diffusion\stable diffusion-webui-forge\extensions\sd-forge-random_prompt_pro\data
a-pi的功能需要自己去注册并登录并在D：\stable diffusion\stable diffusion-webui-forge\extensions\sd-forge-random_prompt_pro\scripts\core.py 中填充入自己的登陆信息，当然我也加入了自定义api功能满足一些人员的需要，在默认的api中能使用的只有Safebooru，其余的api皆需要自己登陆的信息或者其他才可使用
-在第二个分页功能是我做的一个小功能插件，可以在api中随机抽取图片并提取tag，这个功能适合用于参考提示词使用
-如果你发现生成的提示词有语义冲突的你可以将它输入禁用标签里面这样在下次生成提示词的时候就不会出现了
-在多次生成和抽取图片难免会产生缓存卡顿，这时候就可以点击插件下方的清理缓存功能，它会直接作用于内存清理缓存

##下面我就直接发详细的功能介绍了：
-这是一款专为 SD-WebUI / Forge 打造的全能提示词辅助插件，集成智能提示词生成 + Ranbooru 多站点随机图源抓取 双分页功能，界面简洁、逻辑独立、内存级缓存管理，无需复杂配置，开箱即用。

##核心功能亮点
-第一页：智能提示词生成
-智能随机生成高质量正向提示词，自动规避语义标签冲突
-严格限制最多 2 人物，保底不少于 25 个标签
-支持自定义角色关键词、黑名单过滤无用标签
-兼容公共 API 图源 + 本地标签 TXT 双数据源
-一键重置随机种子、内存级清理 API 缓存，不占用硬盘
-生成结果一键直送 Txt2img 绘图框
-第二页：Ranbooru 随机图源抓取
-内置 Safebooru / Gelbooru / Danbooru 三大主流图源
-支持自定义 API 接口，可接入私有图源地址
-可自由设置抓取图片数量 1~12 张，画廊网格预览
-每张图片独立对应专属提示词文本框，互不干扰
-每个提示词框自带独立「发送Txt2img」按钮，单张一键推送绘图
-滑块切换图片数量，对应提示词框 + 发送按钮自动显隐
-一键刷新重新抓取、一键清理内存缓存，拒绝重复图片卡顿

##安装教程
-打开 SD-WebUI / Forge 顶部 扩展（Extensions）
-切换到 从URL安装（Install from URL）
-输入本插件 GitHub 仓库地址
-点击安装，安装完成后重启 WebUI/Forge 即可加载
---
##使用说明
-分页一：提示词生成
-填写角色关键词、需要屏蔽的禁用标签
-选择是否开启 API、本地标签库
-点击「生成提示词」自动生成合规高质量词
-不满意可重置种子重新生成
-生成完成可一键发送到文生图输入框
-接口重复请求卡顿可点击「清理 API 缓存」释放内存
---
##分页二：随机图源抓取
-选择图源站点、设置抓取图片数量
-填写搜索标签（默认 1girl 可自行修改）
-有私有接口可填写「自定义 API」，格式自带 {limit} {tags} 占位符
-点击「获取随机图片」自动拉取图片并解析每张原图 Tag
-每张图片下方独立提示词框可手动编辑修改
-选中满意提示词，点右侧「发送」直接推送到绘图区
-想要换一批图片，点击底部「刷新重新抓取」自动清缓存重抓
